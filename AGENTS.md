# Repository planning and lessons

For this repository, `docs/maintainers/work-log.md` is the canonical replacement
for the generic `tasks/todo.md` convention. Put future plans, checklists,
progress updates and session reviews there.

Use `docs/maintainers/lessons.md` instead of the generic `tasks/lessons.md`
convention for user corrections and lessons. These repository-local paths
override the generic task-management paths. Do not recreate a root `tasks/`
directory.
