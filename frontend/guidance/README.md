# The Non-Vibe-Coded Frontend Design Kit

A practical system for making distinctive, production-grade websites with AI-assisted coding.

This kit is not a component dump or a list of trendy effects. It is a design process. It helps you make choices that are specific to the product, build those choices into a coherent system, and verify that the result is usable, responsive, accessible, and fast.

## Start here

If you have 15 minutes:

1. Read the definition of a non-vibe-coded interface in `PLAYBOOK.md`.
2. Fill in the brief in `PROMPT-PACK.md`.
3. Use the master build prompt from that file.
4. Run the compact pre-delivery checklist in `CHECKLISTS.md`.

If you are building a real product, use the full workflow:

1. Context and brief
2. Visual direction
3. Design tokens and system
4. Functional implementation
5. Focused refinement passes
6. Visual, accessibility, performance, and resilience checks

## The short version

Good AI-assisted frontend work follows the same standard as good human frontend work:

- Begin with a real audience, job, and point of view.
- Pick one memorable idea and execute it precisely.
- Use typography, spacing, content, and interaction as design materials.
- Build a small token system before styling individual components.
- Reuse accessible primitives, then customize them to the brief.
- Review screenshots, not just code.
- Test the awkward states, not only the polished happy path.
- Measure performance and accessibility before calling it finished.
