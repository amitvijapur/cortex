# Maintainer notes

These notes preserve Cortex's build history and working practices. Dated plans,
checklist states and reviews are historical evidence, and may describe earlier
implementations. Use the current guides in [the main README](../../README.md#documentation)
for setup and behavior.

- [Work log](work-log.md) contains plans, progress, decisions and session reviews.
  Add new plans and review results here.
- [Lessons](lessons.md) records corrections and practices to apply in later work.
  Record new lessons here when the user corrects an assumption or approach.

These are the canonical locations for repository planning and lessons. Keep
maintainer notes here so the repository root stays focused on the product.
