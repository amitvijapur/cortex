# Changelog

## 0.1.0, 2026-10-18

Initial versioned packaging of the routing protocol and local CLI. Available tags and release notes are tracked through [GitHub releases](https://github.com/amitvijapur/cortex/releases).

- Markdown routing protocol with explicit workflow choices, effort tiers and capability boundaries.
- Local Python CLI for route declarations, outcomes, corrections, history and advisory retrieval of past routes.
- Installer with registry preservation, skill conflict checks and selected-state-root support.
- Guided Claude Code registry setup, manual Codex integration and documented adaptation paths for other hosts.
- Minimal Direct registry, first-task acceptance guide, update/removal instructions and contribution checks.
- Violet repository social card, recorded offline CLI walkthrough and public onboarding feedback procedure.
- Offline contributor checks and a macOS/Linux CI matrix with pinned actions.

The host agent executes workflows and must follow the protocol. Cortex does not automatically switch models or dispatch routes. Host setup paths differ. CLI fixture checks are not a live host compatibility matrix. Outcome history does not establish better routing, token savings or faster delivery. The optional hosted adviser is off by default.
